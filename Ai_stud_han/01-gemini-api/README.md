What I Learned # 1

Today I started learning how to build applications that interact with Large Language Models (LLMs).
For my first experiment, I used the Gemini API with the Google Gen AI Python SDK to send a user prompt and receive a response from the model.
The goal was simple:

(User Input -> Python Application -> Gemini API -> LLM Response)

What I Built
A simple command-line chatbot that allows the user to continuously send questions to Gemini.
